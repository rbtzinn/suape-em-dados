# Skills aplicadas

As skills abaixo, provenientes do `skillsrbt`, orientaram a primeira implementação:

- `roberto-project-mode`: escopo enxuto, poucas dependências e manutenção simples.
- `compliance-dashboard`: evidência, proveniência e linguagem prudente de conformidade.
- `frontend-premium-mobile`: interface institucional, responsiva e mobile first.
- `react-code-structure`: componentes pequenos, domínio separado da apresentação.
- `backend-simple-api`: rotas diretas, segredos no servidor e respostas explícitas.
- `codex-token-optimizer`: leitura seletiva e alterações concentradas.

Decisões concretas influenciadas por elas:

1. Monólito modular em Next.js, sem microsserviços.
2. Gráficos em CSS/SVG, evitando bibliotecas desnecessárias.
3. Google Sheets atrás de um repositório server-only.
4. Motor de conciliação e política como funções puras testáveis.
5. Modo demonstração sem dados pessoais quando a integração não está configurada.
